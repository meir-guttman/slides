המחלקות Math ו-Random

הרחבת ארגז הכלים ב-Java: חישובים מתמטיים מתקדמים והגרלת מספרים אקראיים.

המחלקה Math

ביצוע פעולות מתמטיות כמו חזקה, שורש, ערך מוחלט ומקסימום/מינימום.

המחלקה Random

ייצור ומניפולציה של מספרים אקראיים למשחקים ולסימולציות.

חלק 1

המחלקה Math - חישובים מתמטיים

ללא צורך ב-new

המחלקה Math מספקת לנו פונקציות מתמטיות מוכנות. אין צורך ליצור ממנה אובייקט! משתמשים בה ישירות דרך שם המחלקה.

Math.abs(x) ערך מוחלט

מחזירה את הערך החיובי של המספר (מרחק מאפס).

Math.abs(-5); // מחזיר 5
Math.abs(3);  // מחזיר 3
Math.pow(base, exp) מחזיר double

מחזירה בסיס בחזקת מעריך ($base^{exp}$).

Math.pow(2, 3); // מחזיר 8.0
Math.pow(5, 2); // מחזיר 25.0
Math.sqrt(x) מחזיר double

מחזירה את השורש הריבועי של $x$.

Math.sqrt(16); // מחזיר 4.0
Math.sqrt(9);  // מחזיר 3.0
Math.max(a, b) / min מקסימום / מינימום

מחזירה את הערך הגדול או הקטן מבין שניים.

Math.max(10, 20); // מחזיר 20
Math.min(4, 8);   // מחזיר 4
לתשומת לבכם: בתוך המחלקה Math קיימת גם Math.random(), אך אנו נלמד לעבוד עם המחלקה הייעודית Random שהיא נוחה וגמישה בהרבה!
חלק 2

המחלקה Random - הגרלת מספרים

נדרש import ו-new
שלב 1: ייבוא (Import)

ייבוא המחלקה מתוך ספריית הכלים של Java.

import java.util.Random;
שלב 2: יצירת אובייקט

יצירת משתנה מסוג Random בעזרת new.

Random rnd = new Random();
שלב 3: הגרלת מספר

שימוש במתודה nextInt(n).

int val = rnd.nextInt(10);

כלל התחום של rnd.nextInt(n)

הפעולה rnd.nextInt(n) מחזירה מספר שלם אקראי בתחום: 0 עד n - 1 (כולל 0, לא כולל n).

🎯 הגרלה בין 1 ל-4 (כמו במשחק שלנו): 
int num = rnd.nextInt(4) + 1;
יוצר מספר מ-0 עד 3, והוספת 1 מעבירה את התחום ל: 1 עד 4.
🎲 הגרלת קוביית משחק (1 עד 6): 
int die = rnd.nextInt(6) + 1;
יוצר מספר מ-0 עד 5, והוספת 1 מעבירה את התחום ל: 1 עד 6.
דוגמה מסכמת

משחק ניחוש מספרים וחישובים מתמטיים

Java Code 
import java.util.Scanner;
import java.util.Random;

public class NumberGame {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random rnd = new Random();

        // 1. הגרלת מספר סודי בין 1 ל-4
        int secretNum = rnd.nextInt(4) + 1;

        System.out.print("נחש מספר בין 1 ל-4: ");
        int guess = scanner.nextInt();

        // 2. בדיקת הניחוש בעזרת תנאי
        if (guess == secretNum) {
            System.out.println("כל הכבוד! ניחשת נכון!");
            
            // שימוש ב-Math במקרה של הצלחה
            System.out.println("המספר בריבוע: " + Math.pow(secretNum, 2));
            System.out.println("המספר בחזקת 4: " + Math.pow(secretNum, 4));
            System.out.println("השורש הריבועי: " + Math.sqrt(secretNum));
        } else {
            System.out.println("טעית! המספר הנכון היה: " + secretNum);
            
            // מתן רמז: האם המספר הסודי היה גדול או קטן מהניחוש
            if (secretNum > guess) {
                System.out.println("המספר הסודי היה גדול יותר מהניחוש שלך.");
            } else {
                System.out.println("המספר הסודי היה קטן יותר מהניחוש שלך.");
            }
        }
    }
}
