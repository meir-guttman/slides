1. למה אנחנו צריכים מערך של עצמים?

התרחיש: אנחנו בונים מערכת לבית הספר וצריכים לשמור נתונים עבור 100 תלמידים.

  • עד כה למדנו ליצור עצם יחיד: Student s = new Student(...);
  • יצירת 100 משתנים נפרדים (s1, s2, s3...) היא בלתי אפשרית!
  • הפתרון: בדיוק כמו שאוספים מספרים לתוך int[], ניתן לאסוף עצמים לתוך מערך מסוג המחלקה: Student[].

2. איך מערך עצמים עובד בזיכרון? (דו-שלביות)

שלב א': הקצאת ה"מדף" (המערך)

Student[] arr = new Student[3];

בשלב זה נוצר מערך בגודל 3, אך כל התאים מכילים null (אין עדיין עצמים!).


שלב ב': יצירת העצמים לתוך התאים

arr[0] = new Student("Dan", 85.5);
arr[1] = new Student("Dana", 92.0);
⚠️ אזהרת NullPointerException: פנייה לתא במערך לפני שנוצר בו עצם (למשל arr[2].getGrade()) תגרום לקריסת התוכנית!

3. מימוש: המחלקה Student

public class Student {
    private String name;
    private double grade;

    // פעולה בונה (Constructor)
    public Student(String name, double grade) {
        this.name = name;
        this.grade = grade;
    }

    // פעולות מאחזרות (Getters)
    public double getGrade() { return this.grade; }
    public String getName() { return this.name; }
}

4. מימוש: מחלקה ראשית (אתחול ידני וסריקה)

public class Main {
    public static void main(String[] args) {
        Student[] classGrades = new Student[3]; // הקצאת המערך

        // אכלוס פרטני של העצמים
        classGrades[0] = new Student("Dan", 85.0);
        classGrades[1] = new Student("Dana", 95.0);
        classGrades[2] = new Student("Gal", 90.0);

        // סריקת המערך וחישוב סכום הציונים
        double sum = 0;
        for (int i = 0; i < classGrades.length; i++) {
            sum += classGrades[i].getGrade(); // גישה לתא i
        }
        System.out.println("Average: " + (sum / classGrades.length));
    }
}

5. מימוש: אתחול המערך בלולאה (עם קלט)

Scanner in = new Scanner(System.in);
Student[] students = new Student[5]; // מערך ל-5 תלמידים

// קליטת נתונים ויצירת עצם בכל סיבוב של הלולאה
for (int i = 0; i < students.length; i++) {
    System.out.println("Enter name and grade:");
    String name = in.next();
    double grade = in.nextDouble();
    
    // יצירת העצם והשמתו בתא הנוכחי במערך
    students[i] = new Student(name, grade);
}

שים לב: בכל סיבוב בלולאה נקרא ה-Constructor new Student(...) ומכניס עצם חדש לתא ה-i.

6. סיכום ותתרגיל כיתה

  • הגדרת מערך: ClassName[] arr = new ClassName[size];
  • יצירת עצם בתא: arr[i] = new ClassName(...);
  • פנייה למתודה: arr[i].methodName()
תרגיל כיתה מיידי:
1. צרו מערך של 4 תלמידים (Student[]) ואכלסו אותם בנתונים.
2. סרקו את המערך ומצאו והדפיסו את שמו של התלמיד בעל הציון הגבוה ביותר בכיתה.
