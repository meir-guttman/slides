מה עושים כשעצם מורכב מעצמים אחרים?

עד כה, התכונות במחלקות שכתבנו היו מטיפוסים בסיסיים (int, double) או String.
היום נלמד ליצור מחלקה שבה אחת התכונות היא מחלקה שאנחנו הגדרנו!

מעגל (`Circle`)

יש לו נקודת מרכז מטיפוס Point

ספר (`Book`)

יש לו תאריך הוצאה מטיפוס Date

תלמיד (`Student`)

יש לו תעודת זהות מטיפוס IDCard

דוגמה ראשונה: נקודה ומעגל

מחלקה בסיסית: Point 
public class Point {
    private double x;
    private double y;

    public Point(double x, double y) {
        this.x = x;
        this.y = y;
    }

    public String toString() {
        return "(" + x + ", " + y + ")";
    }
}
מחלקה מורכבת: Circle 
public class Circle {
    // תכונה מטיפוס Point!
    private Point center; 
    private double radius;

    public Circle(Point center, double radius) {
        this.center = center;
        this.radius = radius;
    }

    public String toString() {
        // קריאה ל-toString של הנקודה
        return "Center: " + center.toString() + 
               ", Radius: " + radius;
    }
}
שימו לב: המחלקה Circle מפעילה את המתודה toString() של האובייקט המוכל בה (center). כך מתקבלת מודולריות וחלוקת אחריות נקייה בקוד!

מערכת ניהול ספרייה: `Date` ו-`Book`

נגדיר שתי מחלקות: מחלקת תאריך ומחלקת ספר שעושה שימוש בתאריך.

1. מחלקה Date
  • תכונות: day, month, year (כולם שלמים).
  • בנאי: מקבל יום, חודש ושנה.
  • מתודה `toString`: מחזירה מחרוזת בפורמט DD/MM/YYYY.
  • מתודה `before(Date other)`: מחזירה true אם התאריך הנוכחי מוקדם מהתאריך other.
2. מחלקה Book
  • תכונות: title, author, ו-publishDate (מטיפוס Date!).
  • בנאי: מקבל שם, מחבר ואובייקט תאריך.
  • מתודה `toString`: מחזירה את הפרטים כולל התאריך.
  • מתודה `isPublishedBefore(Date other)`: משתמשת ב-`before` של התאריך לבדוק אם הספר יצא לפני התאריך המבוקש!

פתרון: מחלקת Date

Date.java 
public class Date {
    private int day;
    private int month;
    private int year;

    public Date(int day, int month, int year) {
        this.day = day;
        this.month = month;
        this.year = year;
    }

    // בדיקה האם התאריך הנוכחי מוקדם מהתאריך המתקבל כפרמטר
    public boolean before(Date other) {
        if (this.year != other.year)
            return this.year < other.year;
        if (this.month != other.month)
            return this.month < other.month;
        return this.day < other.day;
    }

    public String toString() {
        return day + "/" + month + "/" + year;
    }
}

פתרון: מחלקת Book

Book.java 
public class Book {
    private String title;
    private String author;
    private Date publishDate; // תכונה שהיא עצם מטיפוס Date

    public Book(String title, String author, Date publishDate) {
        this.title = title;
        this.author = author;
        this.publishDate = publishDate;
    }

    // שימוש במתודה before של התאריך!
    public boolean isPublishedBefore(Date other) {
        return this.publishDate.before(other);
    }

    public String toString() {
        return "'" + title + "' by " + author + " (" + publishDate.toString() + ")";
    }
}

הרצה ב-Main וסיכום 

public class Main {
    public static void main(String[] args) {
        Date release = new Date(26, 6, 1997);
        Book hp = new Book("Harry Potter", "J.K. Rowling", release);

        Date millenium = new Date(1, 1, 2000);

        System.out.println(hp); // 'Harry Potter' by J.K. Rowling (26/6/1997)

        if (hp.isPublishedBefore(millenium)) {
            System.out.println("הספר יצא לאור לפני שנת 2000!");
        }
    }
}

סיכום השיעור:

1. מחלקה יכולה להכיל תכונות מטיפוס מחלקה אחרת (יחס **Has-A**).
2. המחלקה הכלולה מספקת שירותים (מתודות כמו before או toString) שהמחלקה העוטפת משתמשת בהם.
