1. המבנה והתחביר של משפט תנאי (if)

if (condition) {
    // קוד שיבוצע רק אם התנאי אמת (true)
} else {
    // קוד שיבוצע רק אם התנאי שקר (false)
}

  • סוגריים עגולים (): מכילים ביטוי בוליאני שתוצאתו היא true או false.
  • סוגריים מסולסלים {}: מגדירים בלוק קוד לכל מסלול ביצוע.
  • אופרטורים להשוואה: == (השוואה), != (שונה מ-), >, <, >=, <=

2. דוגמה ראשונה: זכאות לרישיון נהיגה

Scanner in = new Scanner(System.in);
System.out.println("Enter your age:");
double age = in.nextDouble();

if (age >= 16.5) {
    System.out.println("You can start driving lessons!");
} else {
    System.out.println("You are too young.");
}

שימו לב: המחשב יבחן את הביטוי age >= 16.5. רק אחד משני הבלוקים יבוצע!

3. חיבור לידע מוקדם: בדיקת זוגיות במספר

שימוש באופרטור מודולו (%) כדי לבדוק אם המספר עצמו זוגי:

Scanner in = new Scanner(System.in);
System.out.println("Enter a number:");
int num = in.nextInt();

if (num % 2 == 0) {
    System.out.println("The number is EVEN.");
} else {
    System.out.println("The number is ODD.");
}

4. פירוק מספר: בדיקת זוגיות ספרת העשרות

שילוב חילוק שלם (/) ומודולו (%) לחילוץ ובדיקת ספרת העשרות:

Scanner in = new Scanner(System.in);
System.out.println("Enter a two-digit number:");
int num = in.nextInt();

int tens = num / 10; // חילוץ ספרת העשרות

if (tens % 2 == 0) {
    System.out.println("The tens digit is EVEN.");
} else {
    System.out.println("The tens digit is ODD.");
}

5. סיכום נקודות מפתח

🧠 קבלת החלטות: התנאי הופך את התוכנית מצינור פשוט למוח שמגיב לקלט באופן שונה.
⚠️ טעות נפוצה: המופע = משמש להשמה (הכנסת ערך למשתנה). השוואה מתבצעת בעזרת ==!
חלקי ה-else אינם חובה – משתמשים בהם רק כאשר יש פעולה חלופית לביצוע.

6. תרגילים להתחלת עבודה

תרגיל 1: בדיקת זוגיות במספר
קלוט מספר שלם מהמשתמש.
אם המספר זוגי, הדפס: The number is even. אחרת, הדפס: The number is odd.
תרגיל 2: בדיקת סימן המספר (חיובי / שלילי)
קלוט מספר שלם מהמשתמש.
אם המספר חיובי, הדפס: is positive.
אם המספר שלילי, הדפס: is negative.
אם המספר הוא 0, אין להדפיס דבר.
תרגיל 3: מספר דו-ספרתי מעניין
קלוט מספר שלם דו-ספרתי.
אם שתי הספרות שלו זהות, הדפס: nice.
אם הספרות שונות, הדפס: not nice.
